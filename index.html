Os dados foram preservados.

Isto não significa que web e móvel estejam separados. Significa que ambos usam o mesmo cofre, mas alteraram o mesmo registo antes de receber a atualização do outro dispositivo.

Unir web e telemóvel sem perder dados

Foi encontrado um cofre remoto diferente. Introduza o PIN do dispositivo que iniciou a sincronização. A aplicação junta os dois conjuntos de dados, mantém o cofre remoto como identidade comum e alinha este dispositivo automaticamente.

Juntar dados de outro dispositivo

Use isto antes da primeira sincronização quando computador e telemóvel já têm dados diferentes. O backup é decifrado apenas neste dispositivo, os registos são unidos e o cofre atual não é substituído.
